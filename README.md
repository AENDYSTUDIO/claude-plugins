# AENDYSTUDIO Claude Plugins

Плагины NormalDance Protocol для Claude Code.

## Установка

```bash
claude plugin marketplace add AENDYSTUDIO/claude-plugins
claude plugin install ndp@aendy-plugins
export NDP_TOKEN=<ключ NDP>   # бесплатно: Telegram @NORMALDANCE
```

- NDP — 21 MCP-инструмент музыкальных прав: идентификация треков по отпечатку ADNA,
  манифесты прав, верификация артистов, аудит реестра.
- Каналы дистрибуции: официальный реестр MCP (`io.github.AENDYSTUDIO/ndp`),
  npm (`@aendykachess/ndp-mcp`), remote `https://mcp.normaldance.ru/http`.
